# data/ — daily network snapshots

Daily off-node snapshots produced by monad-sonar: testnet/mainnet peer counts discovered via auth-UDP peer discovery, plus mainnet geo/stake distribution and provider concentration (Prague vantage since 2026-07-11; Tokyo before). One file per day under `daily/`, latest mirrored in `latest.json`.

**Archive.** Daily snapshots were committed here until 2026-11-11 and stop there; the files stay as a record. The day-by-day mainnet history (continents, countries, providers) continues in the public geo-latency feed: https://prooflines.org/monad/geo-latency/geo-latency-history-mainnet.json
