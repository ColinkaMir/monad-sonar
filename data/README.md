# data/ — daily network snapshots

Daily off-node snapshots produced by monad-sonar: testnet/mainnet peer counts discovered via auth-UDP peer discovery, plus mainnet geo/stake distribution and provider concentration (Prague vantage since 2026-07-11; Tokyo before). One file per day under `daily/`, latest mirrored in `latest.json`.


**Daily report.** Since 2026-11-12 each day's snapshot comes with a readable report under `reports/<yyyy-mm>/<date>.md` (change against the previous day) and a 14-day overview in [`NETWORK.md`](../NETWORK.md), all generated by `tools/daily_report.py` from the hosted feeds. A day whose feeds are stale or empty is skipped rather than recorded. Snapshots from 2026-07-05 to 2026-11-11 predate the reports. The 2026-11-11 snapshot carries feed values last refreshed 2026-11-10 14:20 UTC: after a reboot the crawler could not start on the new kernel until the buffer-ring fallback below landed.
